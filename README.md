## Description

Text Formatting Everywhere is a utility mod for Forge, Fabric and NeoForge 1.20.5+

Removes restriction in typing section sign (§), therefore you can use [formatting codes](https://minecraft.wiki/w/Formatting_codes) to format text everywhere!

In order to work on a server, server must allow you to type section sign.
